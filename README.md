## Checklist Aksesibilitas Dasar
- [x] Menggunakan elemen HTML semantik (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- [x] Memiliki struktur hirarki heading yang logis (`<h1>` hingga `<h4>`).
- [x] Elemen gambar (`<img>`) menggunakan atribut `alt` yang informatif.
- [x] Form input memiliki atribut `placeholder` yang jelas.
